ข้อ1
- เป็นการจำลองระบบด฿งข้อมูลจากฐาน โดยจะส่งผลผ่านการcallback
- ต้องเช็คค่าerrorก่อนนำข้อมูลไปใช้เสมอ
- ต้องใส่returnหลังเรียกcallback เพื่อสั่งให้ฟังก์ชั่นหยุดการทำงาน

ข้อ2
- เปลี่ยนการเรียกcallback เป็นการใช้ resolveตอนสำเร็จ และใช้ reject ตอนเกิดข้อผิดพลาด
- promisify ช่วยในการแปลงฟังก์ชั่นcallback แบบเดิมให้กลายเป๊นpromiseอัตโนมัติ

ข้อ3
- ใช้ เปรียบเทียบความเร็วของการดึงข้อมูลระหว่างการรอดึงทีละอัน กับดึงพร้อมกัน
- ใช้ promise.all กับ .map เพื่อrequestพร้อมกัน จะช่วยประหยัดเวลา

ข้อ4
- promise.all ใช้เมื่อต้องการข้อมูลครบทุกอัน
- promise.allSettled ใช้เมื่อต้องการรู้ผลของทุกตัว
- promise.any ใช้เมื่อต้องการข้อมูลจากตัวที่ทำงานสำเร็จเร็วที่สุดตัวเดียว
- promise.race ใช้เมื่อต้องการวัดเรื่องเวลากับตัวจับเวลา
